# Состояние беты

Демо опубликовано: https://meme-cv.uprosti.tech

## Реализовано

- [x] Минимальный адаптивный UI: камера, результат, независимый overlay, настройки.
- [x] Необязательная калибровка лица и языка; числовой профиль в браузере.
- [x] Подбор без калибровки после загрузки моделей.
- [x] Диагностика жестов и локальный просмотр области рта.
- [x] Управление media tracks и освобождение созданных моделей при остановке.
- [x] Локальный экспорт PNG.
- [x] HTTPS, отдельный поддомен и разрешающая камеру Permissions-Policy.
- [x] Частичная загрузка сжатых моделей с повторами запросов.
- [x] Линтер, unit-тесты, браузерные smoke-тесты и конфигурация CI.
- [x] README, схема пайплайна и инструкция деплоя.

## До следующего релиза

- [ ] Измерить качество языка и жестов на размеченных записях разных камер.
- [ ] Проверить precision/recall на открытом рте без языка, зубах, улыбке и перекрытиях.
- [ ] Проверить физические камеры в Chrome, Safari и на мобильных устройствах.
- [ ] Проверить первый запуск с пустым кешем через несколько внешних сетей.
- [ ] Добавить Web Worker и замерить p50/p95 latency до и после переноса.
- [ ] Расширить сетевые тесты загрузчика: повторы, отмена, повреждённые манифесты.
- [ ] Прерывать сетевые запросы загрузчика при остановке камеры.
- [ ] Записать демонстрационный ролик на физической камере.
- [ ] Проверить CSP с локальными JS/WASM/blob-ресурсами.

Язык остаётся экспериментальным. Успешные автоматические проверки не означают подтверждённую точность на физических камерах.
