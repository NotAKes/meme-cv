# Развёртывание

Демо: https://meme-cv.uprosti.tech

Приложение статическое. Node.js нужен только для установки зависимостей, тестов и сборки. На сервере нужен HTTP-сервер с HTTPS.

## Сборка

```bash
npm ci
npm run build
```

Публикуется **весь `dist/`**: HTML, JS, CSS, картинки, модели, WASM и сжатые части загрузки. Не загружай только `assets/`: без моделей трекер не запустится.

`postinstall` копирует WASM из npm-пакета. `scripts/pack-models.mjs` после Vite создаёт сжатые части `.task`/`.wasm` по 32 КиБ и манифесты. Загрузчик использует их в production; в dev без манифестов скачивает целые файлы.

```bash
npm run preview
```

Это локальная проверка production-сборки, не production-сервер.

## Caddy

Пример для файлов в `/srv/meme-cv`:

```caddyfile
meme-cv.example.com {
    root * /srv/meme-cv
    encode zstd gzip

    header {
        Permissions-Policy "camera=(self), microphone=(), geolocation=()"
        X-Content-Type-Options "nosniff"
        Referrer-Policy "strict-origin-when-cross-origin"
        X-Frame-Options "DENY"
    }

    @assets path /assets/* /models/* /wasm/* /memes/*
    handle @assets {
        file_server
    }
    handle {
        try_files {path} /index.html
        file_server
    }
}
```

При A/AAAA-записях, указывающих на сервер, и доступных портах 80/443 Caddy получает TLS-сертификат автоматически. В существующем reverse proxy можно направить отдельный домен на внутренний статический контейнер. Публичный Node.js API приложению не нужен.

Не используй `camera=()` в `Permissions-Policy`: это запрещает камеру даже после разрешения браузера. Проверь не только статический сервер, но и заголовки внешнего proxy/CDN.

Для размещения в подпути настрой `base` в `vite.config.ts` перед сборкой. Для отдельного поддомена остаётся `/`.

## Обновление без смешивания версий

1. Собери новую версию и загрузи её в новую папку релиза.
2. Проверь наличие HTML, JS, трёх моделей и WASM.
3. Переключи симлинк `current` атомарным переименованием.
4. Сохраняй предыдущую папку для отката.
5. Не удаляй старые hashed JS/CSS сразу, если открытые вкладки могут ещё обращаться к ним.

Не сохраняй ключ SSH, пароли или конфигурацию с секретами в репозитории. CI этого проекта выполняет проверки и не подключается к серверу.

## После публикации

- HTTPS возвращает валидный сертификат.
- HTML/JS/CSS и модели отвечают 200 с правильным Content-Type.
- `.parts/manifest.json` содержит JSON, а не SPA-fallback HTML.
- Отсутствующий файл модели отвечает 404.
- WASM отдаётся как `application/wasm`.
- Камера запрашивается только после нажатия кнопки.
- Разрешённый видеопоток виден до окончания загрузки моделей.
- Остановка выключает активный track.
- Первый запуск проверен с пустым кешем и через внешнюю сеть.
- Реальная камера проверена вручную; blank-stream smoke-тест этого не заменяет.

При зависании на «Движок» или названии модели проверь Network в DevTools. Видео с камеры и скачивание движка являются разными этапами: разрешённая камера не гарантирует, что сеть уже доставила WASM.
