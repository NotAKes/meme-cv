# Изображения

Пути заданы в `src/data/cats.ts`:

1. `confused-cat.webp`
2. `lululu-cat.webp`
3. `loading-cat.webp`
4. `fist-cat.webp`
5. `salad-cat.webp`

8. `shy-cat.webp`

При замене используй WebP либо меняй расширение в поле `image` записи. Разметка хранит приближённую человеческую позу для подбора, не результат анализа кошачьего лица. Отсутствующее положение лап не превращается в нулевой признак.

Редактора изображений в текущем интерфейсе нет. Изменения файлов становятся доступны после пересборки.
